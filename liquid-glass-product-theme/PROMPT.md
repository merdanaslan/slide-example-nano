# Prompt: Liquid Glass Product Theme

```
Create a presentation about [product/app/topic] in an Apple-inspired minimal Liquid Glass style.

Use translucent interface panels, layered screenshots, soft highlights, rounded cards, floating controls, and plenty of whitespace. Prioritize product visuals over text. Headlines should be short and confident.

The deck should feel like a polished Apple-style feature reveal: simple, focused, elegant, and visually premium.
```
