# Prompt: Modern Premium Theme

```
Create a presentation about [topic] with a modern, premium, polished, minimal, high-end startup aesthetic.

Style: modern, premium, polished, minimal, high-end startup aesthetic.
Tone: confident, clear, intelligent, not corporate-boring.
Design direction: strong visual hierarchy, bold section headers, clean whitespace, limited text per slide, consistent layout system, tasteful icons, subtle data visualizations, and slides that feel like they were designed by a professional designer.

Structure: open with a strong hook, then problem/context, solution/insight, proof/examples, and close with a clear takeaway or call to action.

Make each slide visually distinct but stylistically consistent. Prefer punchy headlines over paragraphs. Use layouts that feel presentation-first, not document-first.
```
