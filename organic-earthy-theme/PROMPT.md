# Prompt: Organic Earthy Theme

```
Create a presentation about [topic] in an organic, earthy, calm brand style.

Visual direction: warm sand, terracotta, and sage green color palette. Soft, irregular CSS blob shapes instead of rigid boxes. Lora serif typography for warmth. Nature-inspired language and metaphors. Gentle, drifting background animations.

Use case: eco-projects, community-focused roadmaps, or softer lifestyle and wellness platforms. Make it feel grounded, calm, and intentional.
```
