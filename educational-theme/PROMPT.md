# Prompt: Educational Theme

```
Create a clean, beautifully designed presentation teaching [topic] to [beginner / intermediate] learners.

Style: modern educational deck, highly legible, engaging, simple diagrams, clear section dividers, visually memorable examples.
Tone: approachable, smart, practical.

Make the content easy to skim and easy to present aloud. Use one key idea per slide. Add visual metaphors, simple frameworks, and recap slides. Avoid wall-of-text slides.
```
